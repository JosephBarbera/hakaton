# «Поймай мошенника» — система выявления подозрительных банковских операций

Прототип системы для хакатона ИИМРТ: анализирует банковские операции,
вычисляет оценку подозрительности и объясняет, почему операция требует
дополнительной проверки.

## Состав проекта

| Файл | Назначение |
|---|---|
| `pipeline.py` | Ядро: загрузка данных, расчёт признаков, обучение модели, выгрузка результатов |
| `app.py` | Веб-интерфейс (Streamlit): таблица операций, объяснения, история клиента, экспорт CSV |
| `clients.csv` | Данные о клиентах (исходные данные хакатона) |
| `transactions_history.csv` | История операций с метками (исходные данные хакатона) |
| `transactions_test.csv` | Новые операции для оценки (исходные данные хакатона) |
| `account_relations.csv` | Связи между счетами (исходные данные хакатона) |
| `results_test.csv` | Результат анализа (создаётся программой автоматически) |

## Требования

- Python 3.10 или новее
- Библиотеки: pandas, numpy, scikit-learn, streamlit, plotly

## Запуск

Все файлы должны лежать в одной папке. В терминале (командной строке)
перейдите в папку проекта и выполните:

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Обучить модель и получить результаты (~10 секунд)
python pipeline.py

# 3. Запустить веб-интерфейс
streamlit run app.py
```

После шага 2 в консоли появятся метрики качества, в папке — файл
`results_test.csv`. После шага 3 терминал покажет адрес вида
`http://localhost:8501` — откройте его в браузере.

## Как работает модель

1. Загружает данные и обрабатывает пропуски (ошибки не приводят к падению).
2. Для каждой операции строит признаки только по её ПРОШЛОЙ истории
   клиента: типичная сумма (медиана), привычное устройство, регион,
   частота операций за последний час — без утечки из будущего.
3. Обучает логистическую регрессию только на операциях с подтверждённым
   итогом (немаркированные не считаются законными).
4. Проверяет качество на отложенном по времени периоде истории.
5. Выдаёт для каждой тестовой операции: оценку риска, категорию
   («норма» / «требует проверки» / «высокий риск») и объяснение на русском.

## Возможные проблемы

| Ошибка | Решение |
|---|---|
| `FileNotFoundError: clients.csv` | CSV-файлы должны лежать в той же папке, откуда запускается программа |
| `ModuleNotFoundError: No module named 'streamlit'` | Выполните `pip install -r requirements.txt` ещё раз |
| «python не является внутренней или внешней командой» | Установите Python с галочкой «Add Python to PATH» или используйте команду `py` |
| Кракозябры при открытии CSV в Excel | Файл в UTF-8 с BOM; откройте через «Данные → Из текста/CSV» |

## Контрольные сценарии (для демонстрации)

В интерфейсе проверяются 7 ситуаций из ТЗ: обычная операция, крупный
законный платёж, серия быстрых переводов, новый получатель и устройство,
нетипичная география, новый клиент, неполные данные — программа не
завершается с ошибкой ни на одной из них

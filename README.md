# «Поймай мошенника» — прототип выявления подозрительных банковских операций

Проект для ИТ-хакатона ИИМРТ. Система анализирует банковские операции,
выявляет подозрительные и объясняет, почему операция требует проверки.

## Состав проекта

- `pipeline.py` — ядро: загрузка данных, признаки, обучение модели, выгрузка результатов
- `app.py` — веб-интерфейс (Streamlit)
- `requirements.txt` — зависимости
- CSV-файлы данных кладутся в ту же папку: `clients.csv`, `transactions_history.csv`, `transactions_test.csv`, `account_relations.csv`

## Запуск

```bash
pip install -r requirements.txt
python pipeline.py        # обучение и создание results_test.csv
streamlit run app.py      # веб-интерфейс
```

## Модель

Логистическая регрессия на признаках, построенных только по прошлой истории
клиента (без утечки из будущего): отношение суммы к скользящей медиане,
несовпадение региона, новое устройство, ночные часы, доля от баланса и дохода,
интенсивность операций за час. Обучение — только на подтверждённых операциях,
проверка — на отложенном периоде по времени.
